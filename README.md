## 🌟 Overview
     
Dive into the fascinating world of the **Travelling Salesman Problem (TSP)** with this interactive educational platform! Built with cutting-edge web technologies, TSP Explorer demystifies one of computer science's most notorious optimization challenges, blending theoretical depth with practical insights from **Design and Analysis of Algorithms (DAA)**.

Whether you're a student grappling with graph algorithms, a developer exploring optimization techniques, or a curious mind intrigued by computational complexity, this project offers a comprehensive journey through TSP's algorithmic landscape.

## 🎯 Key Features

### 📚 Educational Content
- **Comprehensive TSP Definition**: Understand the problem's core concepts and real-world applications
- **Algorithmic Deep Dive**: Explore various solution approaches including brute force, dynamic programming, and heuristic methods
- **Complexity Analysis**: Visual breakdown of time and space complexities for different algorithms
- **Interactive Visualizations**: (Coming soon) Dynamic graph representations and path animations

### 🔬 Technical Highlights
- **Graph Theory Implementation**: Core TSP algorithms implemented in JavaScript
- **Performance Metrics**: Comparative analysis of algorithm efficiency
- **Responsive Design**: Beautiful, mobile-friendly interface that works on all devices
- **Modern Web Standards**: Built with HTML5, CSS3, and vanilla JavaScript

### 📊 Algorithm Showcase
- **Brute Force Approach**: Exhaustive search for optimal solutions
- **Dynamic Programming**: Efficient subproblem optimization
- **Approximation Algorithms**: Near-optimal solutions for large-scale problems
- **Heuristic Methods**: Practical approaches for real-world applications

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Variables for theming
- **Fonts**: Google Fonts (Playfair Display, Syne, JetBrains Mono, Inter)
- **Icons**: Custom SVG implementations
- **Build Tools**: None required - pure static site

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs entirely in the browser

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/adityaakhuntia/TSP-Project.git
   cd TSP-Project
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or serve locally: `python -m http.server 8000` and visit `http://localhost:8000`

3. **Explore!**
   - Navigate through the sections to learn about TSP
   - Study the algorithm implementations
   - Analyze complexity comparisons
